# Changelog

## 1.0.1

- Load the extractor before first-use shortcut and context-menu extraction.
- Wait for clipboard writes and display failure instead of false success; support HTTP pages with a checked clipboard fallback.
- Apply saved image and prompt preferences to popup and background extraction.
- Display custom sponsorship pages, hide unconfigured donation links and validate HTTPS creator URLs.
- Disable copy/download while extraction is pending or failed; ignore obsolete asynchronous results.
- Resolve relative links and images, omit unsafe protocols and preserve article header headings.
- Preserve whitespace and backtick fences in code; quote metadata for valid YAML.
- Support ordered-list start/value attributes, nested-list indentation and Unicode word counting.
- Add background regressions, Chromium integration tests, privacy documentation and reproducible packaging.
